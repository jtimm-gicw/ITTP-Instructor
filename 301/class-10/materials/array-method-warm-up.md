# Array Method Warm-Up Worksheet
## Follow the Array Without Writing Code

### Instructions

You are **NOT writing code** for this activity.

Instead:

1. Start with the given array.
2. Follow each operation in order.
3. Update the array after every step.
4. Write the final array when finished.

### Quick Reference

| Method | What It Does |
|----------|----------|
| `push()` | Adds an item to the END of the array |
| `pop()` | Removes an item from the END of the array |
| `unshift()` | Adds an item to the BEGINNING of the array |
| `shift()` | Removes an item from the BEGINNING of the array |
