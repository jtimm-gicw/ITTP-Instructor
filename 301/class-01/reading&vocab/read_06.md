# 301-Read_02
## Component-Based Architecture & Props

---

## 🧩 1. What is a “component”?

**Answer:**  
A component is a **small, reusable piece of a user interface (UI)**.

👉 Think of it like a **LEGO block 🧱** — you build a full app by combining many smaller pieces.

---

## 🔧 2. What are the characteristics of a component?

**Answer:**  
Components usually have these traits:

- ♻️ **Reusable** → Use the same component in multiple places  
- 🔍 **Independent** → Each component works on its own  
- 📦 **Encapsulated** → Keeps its code (HTML, CSS, JS) together  
- 🧱 **Composable** → Combine components to build bigger features  

---

### 🧠 Key Vocabulary

- **Encapsulated** → Everything the component needs is bundled together  
- **Composable** → Can be combined with other components  

---

## 🚀 3. What are the advantages of component-based architecture?

**Answer:**

- ⏱️ **Saves time** → Reuse components instead of rewriting code  
- 🧩 **Easier to manage** → Smaller pieces are easier to understand  
- 👥 **Better teamwork** → Different people can work on different parts  
- 🧹 **Cleaner code** → Organized and structured  

---

# 🔁 Props in React

---

## 🏷️ 4. What is “props” short for?

**Answer:**  
Props is short for **properties**.

---

## 🔄 5. How are props used in React?

**Answer:**  
Props are used to **pass data from one component to another**.

👉 Usually:
- **Parent component** = gives information  
- **Child component** = receives and displays it  

---

## 🔽 6. What is the flow of props?

**Answer:**  
Props flow in **one direction only**:

👉 **Parent → Child**

This is called **one-way data flow**.

---

### 🧠 Key Vocabulary

- **Parent component** → The component sending data  
- **Child component** → The component receiving data  
- **One-way data flow** → Data only moves in one direction (downward)  

---

# 🎯 Final Takeaway

- Components = **building blocks of your UI**  
- Props = **how data moves between components**  
- Data flows **downward only (parent → child)**  

👉 *Build small pieces, pass data down, and combine everything to create your app.*
