## 1. What Are Variables in JavaScript?  
Variables are **containers that store information** in your code.  
Imagine a variable like a **labeled box** where you keep something you want to use later—like:

- a number  
- a word (string)  
- true/false (boolean)

JavaScript uses variables so your program can **remember information** as it runs.

---

## 2. What Does It Mean to Declare a Variable?  
Declaring a variable means you are **creating it for the first time** and giving it a name.  
You’re telling JavaScript:

> “Make me a new storage box, and I’m naming it this.”

*Example:*
let score;

This creates a variable named score, but it’s still empty.

---

## 3. What Is an “Assignment” Operator, and What Does It Do?

The assignment operator is the *equals sign*:

**=**

It assigns a value to a variable — meaning it puts something inside the variable’s box.

*Example:*

let score = 10;

Here, the value 10 is assigned to the variable score.

---

## 4. What Is Information Received From the User Called?

Information received from the user is called **input**.

Input is anything the user provides, *such as typing, clicking, or choosing an option*.

*Example using prompt():*

let name = prompt("What is your name?");

Whatever the user types becomes the input, and it gets stored in the variable name.

---

### ✅ Quick Summary
| Concept              | Simple Meaning                          |
| -------------------- | --------------------------------------- |
| **Variable**         | A box that stores information           |
| **Declaration**      | Creating and naming the box             |
| **Assignment (`=`)** | Putting a value in the box              |
| **Input**            | Information the user gives your program |
