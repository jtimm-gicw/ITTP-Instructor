# 🖥️ Vocabulary & Reading 1 — Intro to Software Development 101

---

## 🖥️ CLI (Command Line Interface)
A **CLI** is a way to control your computer by **typing text commands** instead of clicking buttons.  

💬 **Analogy:** It’s like giving your computer instructions by talking through **text messages** instead of using a mouse.

---

## 💡 Terminal
The **terminal** is the actual **window or program** where you type those commands (the tool you use to talk to your computer using the CLI).  

💬 **Analogy:** If the CLI is the *language* you speak, the terminal is the *chat app* where you type it.

---

## 🖱️ GUI (Graphical User Interface)
A **GUI** lets you use your computer by **clicking icons, buttons, and menus** — no typing needed.  

💬 **Analogy:** It’s like using a **remote control** with buttons instead of typing instructions.

---

## 💻 IDE (Integrated Development Environment)
An **IDE** is a special program where developers **write, test, and debug code** — all in one place.  

💬 **Analogy:** It’s like a **workshop for coding** — your tools (editor, debugger, terminal) are all in one room.

---

## 🧩 VS Code (Visual Studio Code)
**VS Code** is a popular IDE made by Microsoft. It helps you **write and organize code easily**, with features like syntax highlighting, extensions, and live previews.  

💬 **Analogy:** Think of it as your **digital art studio for coding**, where you can add extra “brushes” (extensions) to make your work easier.

---

## 🧠 Abstraction
**Abstraction** means **hiding unnecessary details** so you can focus on the important parts.  

💬 **Analogy:** When you drive a car, you don’t see how the engine works — you just use the steering wheel and pedals. That’s abstraction in action.

## 1️⃣ What is Markdown?
**Markdown** is a lightweight language used to add **formatting to plain text** — things like headings, bold, italics, lists, and links — without using complex code.  

💡 Think of it as “**simple code for styling text**.”

---

## 2️⃣ Why do we use Markdown?
We use Markdown because it’s:
- **Easy to read and write**
- **Fast to format text** (no complicated HTML tags)
- **Compatible** with many tools like GitHub, VS Code, and documentation sites  

💡 **Tip:** It’s great for writing README files, notes, and project documentation.

---
