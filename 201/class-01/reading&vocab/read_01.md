## 2️⃣ How HTML, CSS, and JS Are Parsed by the Browser

***Answer:***
When the browser loads a website, it reads files in this order:

HTML – builds the structure (what exists on the page)

CSS – applies styles (how it looks)

JavaScript – adds behavior (how it acts)

Parsed means the browser reads the file line-by-line and turns it into something it can display or run.

## 4️⃣ How Do You Create a String vs a Number in JavaScript?

***Answer:***
A String is text and goes in quotes:

let name = 'Jason';


A Number is numeric and does NOT use quotes:

let age = 30;

## 5️⃣ What Is a Variable and Why Are They Important?

***Answer:***
A variable stores data so we can reuse it later.

*Why they matter:*

Store user input

Remember values

Make code flexible and reusable

**Example:**

let userName = 'Alex';

## 6️⃣ What Is an HTML Attribute?

***Answer:***
An HTML attribute gives extra information about an element.

*Example:*

<img src="photo.jpg" alt="A sunset">


src tells the image where to load from

alt describes the image

## 7️⃣ Anatomy of an HTML Element

***Answer:***
Most HTML elements have:

Opening tag

Content

Closing tag

*Example:*

<p>Hello world</p>


<p> → opening tag

Hello world → content

</p> → closing tag

## 8️⃣ Difference Between <article> and <section>

***Answer:***

<article> is standalone content (can make sense on its own)

<section> groups related content inside a page

*Example:*

Blog post → <article>

Sections inside the blog post → <section>

***Answer:***

## 1️⃣1️⃣ How Is the <meta> Tag Used?

***Answer:***
The <meta> tag lives in the <head> and provides information about the page.

*Example:*

<meta charset="UTF-8">
<meta name="description" content="A beginner coding website">

## 1️⃣4️⃣ Why Use <h1> Instead of <span> for Headings?

***Answer:***
<h1> tells the browser and screen readers:

This is the main heading

This content is important

<span> has no meaning—just styling.

## 1️⃣7️⃣ How Can You Add JavaScript to an HTML Document?

**Answer:**
*Three ways:*

***Inline*** (inside a tag)

***Internal*** (inside <script> tags)
